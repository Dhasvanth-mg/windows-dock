# Repository instructions

## Ownership and attribution

Use the owner's configured Git identity for commits. Do not add ChatGPT, Codex, OpenAI, an AI agent, or a bot as an author, coauthor, contributor, or attribution in commits, pull requests, source comments, documentation, or generated project metadata. Omit Co-authored-by and Generated with trailers. Preserve third-party licenses and existing accurate attribution.

## Feature request tracking

Maintain a separate tracker in docs/feature-tracker.md. At the start of every user request, before implementation, record its scope, status, acceptance criteria, and remaining work. Before the final response, record the implementation, verification results, limitations, and outstanding work. Preserve unfinished requests across new messages and context changes. Distinguish built from verified and only mark work complete with evidence. Record the scope and outcome of messages received during ongoing work as well.
