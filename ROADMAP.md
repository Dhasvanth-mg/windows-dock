# Roadmap

1. Document Windows shell feasibility and select the desktop stack.
2. Deliver the functional companion dock with window switching, pins, monitor-aware placement, settings, and clean shutdown.
3. Build the Studio component tree, drag-and-drop editor, live preview, layered themes, component styling, undo/redo, and import/export.
4. Implement auto-hide, fullscreen rules, system controls, and recovery validation. Evaluate Replacement Mode once essential behavior and tray access have been verified.
5. Add popup placement, profiles, conditional rules, permission-scoped widgets, and performance measurements.
6. Verify installation, uninstall, rollback, and release packaging.
