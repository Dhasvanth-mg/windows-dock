# Local image recognition assets

The SqueezeNet 1.1 model comes from the ONNX Model Zoo release with opset 7. See the included Apache 2.0 license and the [upstream model card](https://huggingface.co/onnxmodelzoo/squeezenet1.1-7).

The ImageNet label list comes from Microsoft's Windows Machine Learning sample, commit 02b586811c8beb1ae2208c8605393267051257ae. See the included MIT license and the [upstream label file](https://github.com/microsoft/Windows-Machine-Learning/blob/02b586811c8beb1ae2208c8605393267051257ae/Samples/SqueezeNetObjectDetection/Desktop/cpp/Labels.txt).
